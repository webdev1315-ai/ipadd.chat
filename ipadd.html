IPadd.Chat

Same address, same room. Type any address and talk to whoever typed it too.

Anyone who enters the same address shares this room. It works as a room code and does not connect to that machine.

Examples

  1. Pick an address. Use any IP-style address, like 10.20.30.40, or a word. Share it with the people you want in the room.
  2. Talk. Messages show up live for everyone connected and stay in the room for the next person.
  3. Keep it private by keeping it obscure. Anyone who guesses the address can read the room, so avoid common ones for private chats.
